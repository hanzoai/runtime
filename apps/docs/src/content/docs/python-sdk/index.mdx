The Runtime Python SDK provides a robust interface for programmatically interacting with Runtime Sandboxes.

## Installation

Install the Runtime Python SDK using pip:

```bash
pip install runtime
```

Or using poetry:

```bash
poetry add runtime
```

## Getting Started

Here's a simple example to help you get started with the Runtime Python SDK:

<Tabs>
<TabItem label="Sync" icon="seti:python">

```python
from runtime import Runtime

def main():
    # Initialize the SDK (uses environment variables by default)
    runtime = Runtime()

    # Create a new sandbox
    sandbox = runtime.create()

    # Execute a command
    response = sandbox.process.exec("echo 'Hello, World!'")
    print(response.result)

if __name__ == "__main__":
    main()
```

</TabItem>
<TabItem label="Async" icon="seti:python">

```python
import asyncio
from runtime import AsyncRuntime

async def main():
    # Initialize the SDK (uses environment variables by default)
    async with AsyncRuntime() as runtime:
        # Create a new sandbox
        sandbox = await runtime.create()

        # Execute a command
        response = await sandbox.process.exec("echo 'Hello, World!'")
        print(response.result)

if __name__ == "__main__":
    asyncio.run(main())
```

## Configuration

The SDK can be configured using environment variables or by passing options to the constructor:

<Tabs>
<TabItem label="Sync" icon="seti:python">

```python
from runtime import Runtime, RuntimeConfig

# Using environment variables (RUNTIME_API_KEY, RUNTIME_API_URL, RUNTIME_TARGET)
runtime = Runtime()

# Using explicit configuration
config = RuntimeConfig(
    api_key="your-api-key",
    api_url="https://app.hanzo.ai/api",
    target="us"
)
runtime = Runtime(config)
```

</TabItem>
<TabItem label="Async" icon="seti:python">

```python
import asyncio
from runtime import AsyncRuntime, RuntimeConfig

async def main():
    try:
        # Using environment variables (RUNTIME_API_KEY, RUNTIME_API_URL, RUNTIME_TARGET)
        runtime = AsyncRuntime()
        # Your async code here
        pass
    finally:
        await runtime.close()

    # Using explicit configuration
    config = RuntimeConfig(
        api_key="your-api-key",
        api_url="https://app.hanzo.ai/api",
        target="us"
    )
    async with AsyncRuntime(config) as runtime:
        # Your code here
        pass

if __name__ == "__main__":
    asyncio.run(main())
```
