The Runtime TypeScript SDK provides a powerful interface for programmatically interacting with Runtime Sandboxes.

## Installation

Install the Runtime TypeScript SDK using npm:

```bash
npm install @hanzo/runtime
```

Or using yarn:

```bash
yarn add @hanzo/runtime
```

## Getting Started

Here's a simple example to help you get started with the Runtime TypeScript SDK:

```typescript
import { Runtime } from '@hanzo/runtime'

async function main() {
  // Initialize the SDK (uses environment variables by default)
  const runtime = new Runtime()

  // Create a new sandbox
  const sandbox = await runtime.create({
    language: 'typescript',
    envVars: { NODE_ENV: 'development' },
  })

  // Execute a command
  const response = await sandbox.process.executeCommand('echo "Hello, World!"')
  console.log(response.result)
}

main().catch(console.error)
```

## Configuration

The SDK can be configured using environment variables or by passing options to the constructor:

```typescript
import { Runtime } from '@hanzo/runtime';

// Using environment variables (RUNTIME_API_KEY, RUNTIME_API_URL, RUNTIME_TARGET)
const runtime = new Runtime();

// Using explicit configuration
const runtime = new Runtime({
  apiKey: 'your-api-key',
  apiUrl: 'https://app.hanzo.ai/api',
  target: 'us'
});
```
